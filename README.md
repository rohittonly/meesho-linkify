# 🔗 Meesho Linkify

Generate your own Meesho Affiliate links directly from any Meesho product page.

No more:

❌ Open Affiliate Dashboard

❌ Click Commission Link

❌ Select Facebook

❌ Paste Product URL

❌ Click +

❌ Click Done

Instead:

✅ Open Product

✅ Click Extension

✅ Copy Affiliate Link

---

## Features

- 🚀 One-click affiliate link generation
- 🔒 Uses your own logged-in Meesho Affiliate account
- ⚡ No browser automation
- 📋 One-click copy
- 💻 100% client-side
- 🌐 Open Source

---

## How it works

1. Login to https://affiliate.meesho.com
2. Visit any Meesho product page.
3. Open the extension.
4. Copy your affiliate link.

---

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/meesho-linkify.git
```

Open Chrome

```
chrome://extensions
```

Enable

```
Developer Mode
```

Click

```
Load unpacked
```

Select the project folder.

---

## Privacy

This extension:

- Does NOT collect your data.
- Does NOT store credentials.
- Does NOT send cookies to any server.
- Runs entirely inside your browser.
- Uses your own authenticated Meesho Affiliate session.
